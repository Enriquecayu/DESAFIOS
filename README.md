## 🚀 Cómo contribuir con tu solución

Si quieres resolver un desafío, sigue estos pasos:

1. Elige un desafío (ej. `FACIL/DESAFIO_01/`).
2. Verifica si ya existe la carpeta de tu lenguaje de programación (ej. `JS/`, `PYTHON/`, `RUST/`).
3. **Si no existe:** Crea la carpeta con el nombre del lenguaje en MAYÚSCULAS.
4. **Si ya existe:** Guarda tu archivo dentro de ella usando tu nombre de usuario (ej. `JS/nombre-usuario.js`).
5. Haz el `Commit` y envía tu `Pull Request`.
