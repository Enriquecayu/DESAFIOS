
# FRUTERO
Tienes un tazón en la encimera con un número par de frutas. La mitad son plátanos y la otra mitad manzanas. Necesitas 3 manzanas para hacer una tarta.

# Tarea 
Tu tarea es calcular el número total de tartas que puedes hacer con las manzanas de tu tazón, considerando la cantidad total de fruta que contiene.

# Formato de entrada 
Un número entero que representa la cantidad total de fruta en el tazón.

# Formato de salida 
Un número entero que representa el número total de tartas de manzana que puedes hacer.

# Entrada de ejemplo 
26

# Salida de ejemplo 
4

# Explicacion
Si tienes 26 piezas de fruta, tienes 13 manzanas, lo que hace 4 tartas y sobra una manzana, tambien imprime la cantidad de manzanas que sobran.
