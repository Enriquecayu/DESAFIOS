
# ARGENTINA
Estás en una sombrerería en Argentina. Los precios están en dólares estadounidenses y pesos argentinos. Tienes ambos, pero quieres asegurarte de pagar el precio más bajo. ¿Pagas en dólares o en pesos? El tipo de cambio es de 2 centavos por cada peso.

# Tarea 
Crea un programa que tome dos precios y te indique cuál es el más bajo después de la conversión.

# Formato de entrada 
Dos valores enteros: el primero es el precio en pesos y el segundo, el precio en dólares.
# Formato de salida 
Una cadena que indica en qué moneda debes realizar la compra ('Dólares' o 'Pesos').

# Entrada de ejemplo 
4000 100

# Salida de ejemplo 
Pesos

# Explicacion
Debes usar Pesos para comprar el sombrero ya que 4000 pesos equivalen a 80.
