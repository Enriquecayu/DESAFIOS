
# POPSICLES
Tienes una caja de paletas y quieres regalarlas a un grupo de hermanos y hermanas. Si te sobran suficientes para darles la misma cantidad a cada uno, ¡adelante! Si no, se pelearán por ellas y tendrás que comértelas tú mismo después. 

# Tarea 

Dada la cantidad de hermanos a los que les vas a dar paletas, determina si puedes darles la misma cantidad a cada uno o si no deberías mencionarlas. 

# Formato de entrada 
Dos valores enteros: el primero representa la cantidad de hermanos y el segundo la cantidad de paletas que quedan en la caja. 

# Formato de salida 
Una cadena que dice "regalar" si las vas a regalar, o "comérselas tú mismo" si las vas a comer tú mismo. 

# Entrada de ejemplo 
3 9 

# Salida de ejemplo 
regalar

# Explicacion
Puedes darles las paletas a los hermanos y hermanas porque cada uno recibira la misma cantidad, 3.
